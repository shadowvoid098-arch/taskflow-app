HOW TO INSTALL
══════════════

── ANDROID PHONE (Chrome) ──────────────────────────────────
1. Open Chrome browser on your phone
2. Go to: File Manager → open the taskflow-app folder → open index.html
   OR upload to any web server / Google Drive and open the link
3. Tap the 3-dot menu (⋮) in Chrome
4. Tap "Add to Home screen" or "Install app"
5. Tap "Add" — TaskFlow icon appears on your home screen!

── iPHONE / iPAD (Safari) ──────────────────────────────────
1. Open Safari and navigate to your TaskFlow file
2. Tap the Share button (□↑) at the bottom
3. Scroll down and tap "Add to Home Screen"
4. Tap "Add" — done!

── WINDOWS (Chrome or Edge) ────────────────────────────────
1. Open index.html in Chrome or Microsoft Edge
2. Look for the install icon (⊕) in the address bar
   OR click the 3-dot menu → "Install TaskFlow"
3. Click "Install" in the popup
4. TaskFlow opens as a standalone window, like a real app!

── MAC (Chrome) ────────────────────────────────────────────
1. Open index.html in Chrome
2. Click the install icon in the address bar
   OR Chrome menu → "Install TaskFlow"
3. Click Install — it appears in your Applications folder!

── LINUX (Chrome/Chromium) ─────────────────────────────────
1. Open index.html in Chrome or Chromium
2. Click install icon in address bar or Chrome menu
3. Click Install

── QUICK OPTION (No install needed) ────────────────────────
Just double-click index.html to open in any browser.
It works fully without installing!
